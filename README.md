# Fear-RSI v1.1

모바일/PC용 Streamlit 퀀트 연구 대시보드. 자동 주문 기능 없음.

## 업그레이드
- RSI 단독(A), RSI+공포탐욕(B), RSI+공포탐욕+SMA200(C) 동시 비교
- 전략별 거래 횟수, 승률, 수익률, MDD, 평가금액 및 자산곡선
- 최근 확정봉의 조건별 통과/미통과 진단
- 기존 C 전략의 차트, 거래 CSV 및 설정 유지

## 배포
GitHub 저장소 최상위에 `app.py`, `requirements.txt`, `README.md` 업로드. Streamlit Cloud의 Main file path는 `app.py`.

## 유의사항
- 4시간봉 다음 시가 체결 가정, 고정 수수료·슬리피지, 간략화된 손절/익절 체결 모델.
- 공포탐욕지수는 Alternative.me의 글로벌 지표로, 업비트 KRW 시장 자체 지표가 아님. 전일 UTC 날짜를 사용하지만 발표 시각 완전 검증은 아님.
- 데이터 공백, 체결가능성, 과최적화, 시장별 비교, 미사용 구간 테스트 등 추가 검증 필요.
- 신호는 투자 권유가 아니며, 실거래 전 모의매매 검증 필요.
