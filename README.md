# Fear-RSI v1.2

업비트 BTC/ETH 4시간봉 + RSI + 전일 공포탐욕지수 + 일봉 SMA200 연구용 Streamlit 대시보드.

## v1.2 변경
- 전략 A/B/C 수익률, MDD, 시장 노출 비교
- 선택 전략의 거래별 순손익, 승률, 평균 수익/손실
- 손절/익절/RSI/시간 만료별 청산 원인 집계
- 거래별 손익과 누적 실현손익 그래프, CSV 다운로드
- 단계별 매수 조건 충족 봉 수
- RSI, 공포 상한, 손절/익절, 최대 보유시간 실험용 설정
- 갭 하락 손절의 보수적 가격 가정

## 설치
`pip install -r requirements.txt`
`streamlit run app.py`

기존 GitHub 저장소의 세 파일을 교체하면 Streamlit 배포가 갱신됩니다.

## 주의
연구용 백테스트이며 실제 거래소 체결/실시간 신호가 아닙니다. 지수 게시 시각, 데이터 결측, 거래 비용과 과최적화를 별도 검증하세요.
