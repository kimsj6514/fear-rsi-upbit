# Fear-RSI v1.6 — 전체 시장 기회 연구

BTC/ETH 4시간봉 전체를 분석하고 D1/D2/D3 매수 신호와 비교합니다.

## 기능
- 365~1440일 과거 데이터 수집 (API 제한 및 응답 시간 주의)
- RSI, 공포, 거래량, 시장 국면, 매수 기회 점수별 1·3·7·14일 수익률
- 거래비용 반영 수익률, MFE, MAE, 하위 10% 수익률
- 개발 70% / 검증 30% 분리, 미래 수익률 경계 넘김 방지
- 전체 4시간봉 기준과 D1/D2/D3 신호 비교
- 종목/기간/표본 간격/수수료/슬리피지 선택 및 CSV 다운로드

## 변경 주의
이번 v1.6은 전체 시장 연구에 집중하도록 화면을 재구성했습니다. v1.5의
개별 거래 포지션 백테스트 및 청산 방식 비교표는 포함하지 않습니다.
이전 버전은 GitHub 커밋 기록으로 보관할 수 있습니다.

## 설치
Streamlit Cloud에서 `app.py`, `requirements.txt`, `README.md`를 교체합니다.

## 한계
API 요청 시간 및 호출 제한, 캔들 누락, 공포지수 게시 시각, 수익률 표본의
시간적 상관, 슬리피지 모델 및 표본 선택 편향은 실전 적용 전에 검증해야 합니다.
수익률은 과거 자료에 근거하며 미래 수익을 보장하지 않습니다.
